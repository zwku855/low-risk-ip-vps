## **为什么你的IP总是被风控盯着不放**

平台的反欺诈系统不是吃素的。它们手里握着一份又一份的IP数据库，把你这个IP的来路扒得清清楚楚。判断逻辑其实不复杂，主要看几样东西：

- **IP归属类型**：是来自数据中心（hosting/datacenter），还是来自真实的家庭宽带（residential）。数据中心IP天生就带着"可疑"标签，因为正常用户不会从机房上网。
- **IP风险评分（fraud score）**：这个分数综合了IP的历史行为、所在ASN、地理位置一致性、是否曾被滥用等因素。业内经验是，分数控制在30以下相对安全，越低越好。
- **IP纯净度**：这个IP之前有没有被别人注册过一堆账号、发过垃圾邮件、被多个风控数据库标记过。一个"二手"IP，再便宜也是坑。

机房IP的问题就在这：它既是datacenter类型，又往往因为便宜被大量用户轮换使用，纯净度早就被糟蹋得差不多了。所以懂行的人宁可多花点钱，也要找**住宅IP**或**双ISP家宽IP**的VPS——这种IP在风控系统看来，跟你家隔壁老王用Comcast上网没区别，天然就是低风险。
